# Agent Note: 创伤生理应激豁免与破防恶言模式（真实感补丁）

Status: implemented
Date: 2026-10-21

## Problem

三层去味与 `findStockReactionTic` 检测器把「冷汗、咬牙、攥拳、充血怒目」这类生理应激与套式通用反应同等对待，实战中会把真实创伤下的血肉反应也标成 AI 味删掉，正文被修成全员麻木面瘫；同时底层市井对峙场景缺少专属对话模式，写手套用上层权谋的高冷一字禅与哲理金句，反派被当众削面子后还能优雅微笑，情绪烈度整体失真。

## Decision

- 五份同源 banned-words.md（story-deslop / story-long-write / story-review / story-short-write / story-setup agent-references）申明：真实创伤、剧痛、生死逼迫下承担明确生理后果的应激不属于「套式通用反应」，但单章力度副词同词不超 2 次、同一小动作不跨角色复用。
- `findStockReactionTic`（四个 skill 的同源 check-ai-patterns.js）在计数前先取句子样本，命中 `骨|碎|裂|折|断|血|创|碾|砸|掐|勒|刃|伤口|皮开肉绽|肿黑` 的句子豁免——只认器质性创伤结果，防止无伤状态下的套词自我豁免；`sample` 声明相应前移。
- 三份同源 dialogue-mastery.md 加「破防恶言模式」小节与模式表行，把「情绪水肿咆哮」收窄为「无实质矛盾的空喊」。
- 两份同源 opening-design.md 加首章硬上限：物理空间转换 ≤2、首场核心冲突 ≥50% 篇幅、金手指停在悬念点、反派威胁后主角行为自洽、拉开情绪温差。
- build_writer_prompt.py 与 writer-prompt-fallback.md 同步四条硬约束（情绪温差、物理状态机、POV 边界、砍口号金句），脚本拼包与手动组装共用同一口径。
- doc-budget.json：narrative-writer 各分支 +420~810、最坏叠加 +1200（29800 → 31000，硬上限 35000 不变）。

## Alternatives considered

- 豁免不做关键词门、直接放宽整个 `findStockReactionTic` 的密度阈值：最省事，但无伤状态的套词复读（AI 指纹本体）会一并漏网，检测器失去意义。
- 把生理应激豁免做成独立白名单词表文件：可精确逐词控制，但又要多一份跨 5 个 skill 同步维护的资料，且句子级创伤语境比词级白名单更贴近判断本意。
- 新规则只写进 skill 文档、不动检测器：文档与检测器口径会漂移，写手按手册写的应激仍被检测器标红。

## Consequences

收益：带伤角色的真实反应不再被去味误删；底层冲突的情绪烈度有据可写；写手任务包里物理连续性与 POV 边界有逐章执行的硬约束。代价：创伤关键词里的单字（断/折/裂/血）也会命中非创伤语义（如「打断」「心血」），产生少量漏报；该 finding 本就是 advisory 级，接受假阴性优先于假阳性。写手路径预算上调后余量收窄（常规章约余 13 字），下次加正文须先删等量旧文或再调预算。
