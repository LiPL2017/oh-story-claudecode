# 对话设计操作手册

> 写对话场景时读取，按角色关系、场合和目的选择写法。

---

## 决策路由

| 你的对话场景是 | 用这种模式 | 操作 |
|-------------|---------|------|
| 主角碾压/打脸 | 压制模式 | 对方长篇大论 → 主角一字回应 |
| 主角亮底牌/反转 | 反转模式 | 对方嚣张 → 主角一句话事实 → 对方沉默 |
| 关系破裂/心死 | 心死模式 | 对话越回越短：从辩解 → 沉默 → "随意" |
| 日常互动/立人设 | 日常模式 | 让其他人物参与冲突，不要主角一个人独白 |
| 群众震惊/弹幕 | 弹幕模式 | 递进：普通人震惊 → 专业人士分析 → 特殊身份者反应 |
| 信息展示/世界观 | 信息嵌入 | 用角色语气包裹信息，不是机械陈述设定 |
| 情绪拉扯/虐心 | 情绪推动 | 上行下行交替，像拉锯拉升期待 |
| 底层对峙/当街撕破脸 | 破防恶言模式 | 恃强凌弱者露出暴虐嘴脸，受挫后气急败坏失态；被压迫者带血腥痛感发狠 |

### 对话模式选择补充

问答式像审讯 → 让一方主动说，另一方用台词、动作或心理回应；冲突式按处境选语气；多人对话写前定清谁提供信息、谁加剧情绪、谁制造冲突。

## 对话核心规则

一段对话至少承载以下一项，都不承载就删，或用叙述带过：

1. **推进剧情**：透露新信息、推动事件发展
2. **增加期待感**：暗示即将发生的事、制造悬念
3. **展示人设**：通过语言风格传递角色性格

且在情绪场景里，每句还要**回应上一句对方的情绪状态**（承接/偏转/升级/退缩）——对话是两个人的情绪在碰，不是轮流播报信息。只推进剧情、句间无情绪承接 = 机械对话。

### 绝对禁止

| 禁止 | 理由 |
|------|------|
| 配角无脑夸主角 | 缺少立场与事实依据 |
| 互相解释读者已知信息 | 水字数 |
| 大段说明文式对话 | 对话停止交锋，只剩讲解 |
| 所有角色说话方式一样 | 遮住名字便分不出说话者 |
| 无依据便被说服 | 转变应有新信息、利益或处境变化支撑 |
| 情绪无故转向 | 转向前要有触发的事或话 |
| 捧哏工具人、鹦鹉复读对方原话 | 配角只剩接话功能 |
| 高位者长篇自证、说话不分场合 | 身份和处境塌了 |
| 虚假空洞的情绪水肿咆哮（无实质矛盾却空喊口号） | 越吵越假；但生死逼迫、极端羞辱下的真实破口大骂、暴怒失态与濒死痛嘶不在此限，必须敢于写出情绪烈度 |
| 悬念正攒着就被台词说破 | 期待提前泄掉 |

## 真实冲突对峙与破防恶言

### 规则
底层市井冲突、生死羞辱场景，严禁套用上层权谋的高冷“一字禅”与“哲理金句”；深宅权谋场景则须拉开主配角的“情绪温差”（以配角的贪喜、暴躁、怕担责反衬主角的静水流深）。

### 破防恶言模式
- **反派撕下伪装**：仗势欺人者在顺境时暴虐轻蔑、言语恶毒；当众吃瘪、被刀架喉或优势被打破时，必然产生惊惶失措、色厉内荏，进而恼羞成怒、迁怒失态。严禁反派在被当众削了面子后还能“优雅捻玉牌微笑着讲人生哲理”。
- **弱者受创应激**：被踩在脚下的弱者，绝不可超然作揖或理智背诵法条，也不必喊中二口号。必须体现出人在遭受肉体剧痛时的生理抽搐、冷汗浸透与死死咬牙的执念。
- **旁观者市井常识**：围观群众不要只有统一的“齐齐一静”，要有市井看热闹的指指点点与凉薄起哄，但底层看客的行为必须符合生存常识（如绝不会为了起哄而把花钱买来的吃食扯碎扔进泥里）。

## 权力博弈对话

### 规则

对话长短可以表现权力变化：掌控者简短回应，被动者不断解释。具体长度仍取决于人物和处境。

### 压制模式

结构：对方长篇大论（3-5 行）→ 主角一字回应。

```
"你以为你是什么东西？我告诉你，这个家轮不到你说话！你嫁进来的那天起就该明白自己的位置。"
"滚。"
```

### 反转模式

结构：对方嚣张（2-3 行）→ 主角亮底牌（1 行事实）→ 对方沉默。

```
"你有什么资格管？这是我家的钱，我想怎么花怎么花。"
"你妈的存折，密码是我的生日。"
```

### 心死模式

结构：对话越回越短，从辩解到沉默到「随意」。

```
"你听我解释，那天不是你想的那样。"
"嗯。"
"真的，我可以证明。"
"随意。"
```

### 操作指令

- 亮底牌时突出改变局势的事实；解释和动作只留有作用的部分。
- 被压制方可通过辩解、沉默或行动暴露处境，不按字数分配话轮。

## 潜台词与议程

### 潜台词规则

- 试探与博弈时，把真实动机藏在借口、回避或话外之意里；坦白、求救、告知可直接说目的。
- 为博弈对白同时设计角色想得到什么，以及他用什么理由开口。

### 对话议程

- 每个角色进入对话时有自己的议程：想从这场对话中得到什么
- 两个角色的议程碰撞才是张力来源
- 双方议程一致（同立场）= 复述，失去意义

### 明面要什么 / 真正想要什么

每场对话、每个参与者都写两栏，写不出来说明这场不需要他开口：

- **明面要什么**：他嘴上提的要求
- **真正想要什么**：情绪层面的真实所求（被看见、被放过、被承认、让你难受、确认你还在不在意）

两栏相同 = 没有潜台词：要么是刻意的坦白（标明），要么这场得加压力。细纲的「出场人物情感清单」写这两栏，正文只写结果。

### 语气由三要素决定

关系 × 场合 × 目的 = 语气

| 场合 | 特点 | 适合内容 |
|------|------|----------|
| 私人（单对单） | 深入、感情流露透彻 | 内心剖白、密谋、表白 |
| 公众 | 需考虑体面，措辞收敛 | 需要冲击力时可打破（如当众翻脸） |
| 熟人（朋友/同门） | 深度介于两者之间 | 轻松互动和信息交换 |

私密的话在公众场合说才有冲击力。对话中不能完全表达的内容，通过动作、神态、环境补充。

## 情绪推动对话

### 强情绪对话

- 命令式+否定式最能激发读者情绪："我说的还不够清楚吗？"
- 最强话术：打着为你好的幌子，句句不离关心，但句句都是嫌弃、指责、厌恶
- 直接否定比含蓄暗示更伤人

### 情绪连续性

情绪转变要有触发依据。新证据、决定或关系变化可以造成骤变；没有触发便突然改变态度时，补清原因，不强行写满每一级情绪。

### 情绪与行动的因果检查

按 事件（失衡）→ 情绪反应 → 内心判断（只写影响理解的判断）→ 行动 检查转变是否成立，不要求逐步写满；上下文已清楚的反应或思考无需补写。

### 对话不平淡三思路

- 对话本身带来/强化某个核心驱动力（期待、爽感、悬念）
- 信息交流因某原因受阻碍，阻碍可能导致驱动力到来
- 发展突然脱离读者预期（但必须合理、符合人设）

## 信息展示与世界观引出

- 大量信息通过对话展示会显得啰嗦，部分信息转化为情节、心理描写、旁白、环境、动作
- 用角色的语气和立场包裹信息，不是机械陈述设定
- 设定用到哪个稍微带出来就行，不需完完全全讲明白前因后果
- **角色不当"科普嘴"**：按角色当下的目的和对话阻力取舍设定、原理和前因后果，用到哪带哪点。台词同样不做空转解释，不用身体反应填补解释段。

### 信息拉扯示例（以"主角新书起飞了"为例）

| 角色 | 台词 | 功能 |
|------|------|------|
| 甲 | 听说成绩出来了 | 悬念拉期待 |
| 乙 | 肯定没人看！ | 下行 + 拉期待 |
| 甲 | 听说成绩很不错 | 上行 + 拉期待 |
| 乙 | 首订一万三？ | 展露核心信息 + 达成爽点 |

上行和下行交替，情绪像拉锯不断拉升期待。

## 人物语言差异化

每个角色要有自己的说话方式。对话时经常卡住不知道角色会说什么 → 人设模糊，去总结类似人设的说话方式。

| 差异化维度 | 操作 |
|------------|------|
| 惯用语 | 有身份或经历来由才给，不给每人硬配口头禅 |
| 说话节奏 | 长篇大论 vs 短句连击 |
| 信息偏好 | 技术型带专业术语，江湖人带切口 |
| 立场固定 | 某角色永远从某个角度发言（悲观派/乐观派/务实派） |
| 身份影响措辞 | 老者/少年/贵族/市井，身份不同则措辞、自称、敬谦词不同 |
| 性格影响语气 | 智谋型话里有话；鲁莽型想到什么说什么；冷静型措辞精确，偶尔情感外露反而有冲击 |
| 进度影响态度 | 初见/熟悉/对立/亲密，关系阶段不同则语气与信息量不同 |

### 语言指纹（可检验）

上表是设计层；让读者遮住名字也认得出人的是这四项，细纲清单与正文都按它对齐：

1. **句法特征**：短句连击还是长句缠绕；问句多还是判断句多；说话成不成完整句（有人结巴，有人只答事实）
2. **称谓与口头语**：怎么称呼对手（「本姑娘」「老混蛋」）；口头语要有身份或经历来由，不硬配
3. **受压时退守的话题**：被逼到墙角时他转去说什么（讲规矩、翻旧账、说别人的不是）
4. **绝不碰的话题**：什么话题一出现就沉默、岔开、发火或走人

内敛的人物尤其需要标记——一个可识别的语言习惯（结巴、只说半句、只答事实）就是他的标记：冷不等于没有特征。

## 台词的句式

台词不是文档在陈述，不能一水儿的主谓宾加句号。日常说话的句式要混着用，疑问、反问、倒装、感叹、祈使、省略各占一点：

| 句式 | 例 | 常用在 |
|------|----|--------|
| 疑问 | "谁说的？" | 接话、试探、不认 |
| 反问 | "我怎么知道？""这还用问？" | 顶撞、堵人、不耐烦 |
| 倒装 | "怎么了你。""说话啊你。" | 急、嗔、亲近、不耐烦 |
| 感叹 | "好得很！" | 情绪外露 |
| 祈使命令 | "拿过来。" | 权力、吩咐 |
| 省略半截 | "那可不。""随你。" | 敷衍、心冷、懒得争 |
| 重复强调 | "不行。就是不行。" | 强硬、发狠 |

信息量大的长台词（讲情报、讲规矩、翻旧账）不能一口气说到底：用极短句在中间劈开——「侯爵。」「喊，是没用的。」「是要做出来的！」短句承担态度，长句承担信息。

自检：把一章台词按句末标点分类，陈述句超过八成就是机器人在说话。句式偏好也是人物特征——有人永远用问句，有人只会下判断，有人成句成句地说完，有人只蹦词。

## 口语的毛边

通篇台词都成完整句、句句落在句号上，读起来就是一群机器人在轮流播报。**每场对话至少两处毛边**：

| 毛边 | 写法与用法 |
|------|-----------|
| 打断 | 话没说完被打断，或抢在别人前面接话（争执、急事、权力压制） |
| 答非所问 | 回的不是对方问的那句，而是他真正在意的另一面（隐瞒、心虚、试探） |
| 改口 | 说到一半换词、降调、把「你」改成「您」（露怯、退让、临时找补） |
| 半句话 | 只报一半就停住，让对方追问（手里有牌、吊着人） |
| 沉默 | 不答，用一个动作代替：低头、换手、看别处（压迫、忍着、认输） |
| 称呼变化 | 称呼一改，关系就变了（「陈姑娘」→「沈姑娘」） |

自检：每场至少两处毛边；连续三句台词之间没有动作、停顿或被打断，就要拆。

## 弹幕/群众对话

作用：透露主角不知道的信息、拉期待、渲染情绪；锦上添花，不代替主线。写法：走递进（普通人震惊 → 专业人士分析 → 特殊身份者反应 → 情感升华），各条人格化语气不同、每条不超过一句话核心信息；可让看似路人一句话改变所有人认知。关键爽点/燃点/泪点前后集中用，不每章写。

## 节奏控制

### 大量对话保持节奏

- 不要删掉表现人物性格的语气助词来"精简"
- 对话段落间穿插动作描写、环境变化、心理活动调节节奏
- 紧张段落对话短促，舒缓段落可以长一些
- 关键信息放对话开头或结尾，中间用于拉扯情绪

### 动作和表情处理

- 刻意给每句对话配表情/动作会让行文机械
- 动作和表情在关键转折处使用效果最好，不需要每句都配
- 语气平淡场景（喝茶、散步）用微小动作和沉默体现氛围

### 对话的呼吸感

- 连续多轮对话后需要"换气"，插入环境描写或角色心理
- 适当停顿（动作描写、换行、短句）比连续输出更有张力
- "你确定？"比长篇解释更有压迫感

---

## 篇幅控制

### 过多与过少

- 过多：读者已知信息用叙事一句话概括（"她把进城的缘由说了一遍，表姐听完直皱眉"），能用突发状况替代的直接替换；语气词删掉后干巴巴 = 本身缺信息量，需重写
- 过少：能用其他人物讲出来的，不要让主角旁白平铺直叙；引入配角参与冲突，但新人物必须安排主线戏份

## 以梗填充对话

### 梗式 vs 普通

- 普通："兄弟别灰心，你一步步走到今天我是看着你过来的，这点挫折对于你来说算什么事儿？振作起来！"
- 梗式："兄弟别灰心，我相信你总有人头落地，落地人头，头落地上，卧槽那句话怎么说的来着？兄弟你懂我意思吧。"
- 梗式用"说不出来但意思到了"的状态制造趣味

### 操作

- 在对话中融入梗或骚话提升趣味；主角或重要配角的突出对话适合用梗强化记忆点，可把某个梗作为高潮点、整段剧情围绕达成它来设计
- **场合例外（声线让位）**：高压/生死/悲痛/严肃 beat 里，搞笑担当与轻快配角的玩笑、口头梗、插科打诨一律收敛——声线让位于当前情绪基调，用短、冷、带情绪重量的反应替代；梗只在安全或喘息 beat 放。自检：这句玩笑放进当前基调会不会让读者出戏？会就删/改

## 质量检查

### 三大自查项（中一条以上需改进）

- [ ] 是否存在大量信息都必须用对话来展示
- [ ] 对话是否是问答式的一问一答
- [ ] 是否习惯依赖对话来推动剧情或人物变化

### 核心指令检查

- [ ] 权力博弈：话轮长短、回应方式与人物掌握的筹码相符
- [ ] 潜台词与议程：每个角色进入对话时有自己的议程，试探时动机与说辞有差异
- [ ] 人物差异化：遮住角色名后能否区分是谁在说话（按上表各项）
- [ ] 弹幕递进：普通 → 专业 → 特殊身份，是否有层次感
- [ ] 对话推动剧情：每段对话结束时，剧情是否往前推了一步
- [ ] 说完必须变：一场对话结束时至少一个人的状态与开场不同；都没变就删或并
- [ ] 毛边与句式：一场至少两处毛边；台词不是一水儿陈述句，疑问/反问/倒装/感叹/省略混着用
- [ ] 情绪直给为主：态度用情绪词与情态词写出来（笑法、语气、称呼），肢体动作加码不替代；抽象心理陈述一章不超三处
- [ ] 篇幅控制：按场景职责判断是否过长，删去复述和无效往返，不按固定占比分配

### 检验对话质量

- 对话自然度检查：逐句检查对话是否像自然口语交流，而非书面化的问答稿
- 对话结尾能否预示接下来的节奏变化
