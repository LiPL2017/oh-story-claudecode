# 情绪落到纸面：写一章时的情绪执行

> 细纲与单元卡已经定了本章的目标情绪和它在弧线上的位置；本文件只管写这一章时怎么把情绪写出来。选弧线、排节奏、管期待是排纲时的事，见 emotional-arc-design.md。

## 情绪核心公式

写每个场景时分离三层情绪：
1. 角色自己的情绪（角色感受到的）
2. 文本传递的情绪（文本要让读者感受的）
3. 读者实际感受的情绪（读者真正的体验）

同一场景三层可以完全不同：角色在哭，文本在撩，读者在爽。

例：女主当众被退婚。角色：屈辱；文本：她笑着应下；读者：憋着火，等后面打脸。

---

## 前反应-发生-后反应情绪结构

用于虐/悲壮/遗憾类场景。按顺序执行三步：

1. **前反应**：让读者提前知道坏结果，然后描写美好事物（读者预知法）
2. **发生**：让坏结果真的发生
3. **后反应**：主角真情流露，作出改变（愤怒/拼命/振作）

操作示例：知道某人一天后要死 -> 让她经历美好（逛街、看烟花） -> 她真的死了 -> 主角愤怒拼命

---

## 弱者获援的情绪结构

用于强者介入、弱势群体重获士气的热血场景，按四步展开：

1. **前反应**：铺垫弱者的苦，用对比强化（现在的弱 vs 以前的强）
2. **发生**：强者到来，"我知道你们苦，我来了"
3. **后反应**：弱势方被拯救
4. **士气如虹**：整体气势转变

## 基于不该如此的情绪驱动

- "不该如此"是最根本的情绪驱动力——写诬告、不公、恃强凌弱，读者天生生出"不该如此"的念头
- 核心情绪逻辑：想要爽，必先不爽；想要公平，必先不公平；想要强大，必先不强大
- "悬而未决"也是强驱动力
- 好的题材必须具备勾起人们惋惜、渴望改变的特质

---

## 理念矛盾的情感爆发力

- 理念之争比利益之争更能引发读者深层共鸣
- 少量关键场景即可，不需要大量笔墨
- 理想主义与现实的冲突是塑造配角封神级人设的手法
- 理念认同 = 人设认同 = 读者情感投入
- 在主线中穿插理念型角色，用他们的追求和牺牲拔高全书情绪上限

---

## 情绪调动的三层方法

三层：**长期感情投入**、**短期事件冲突**、**场景描绘**。三者可叠加，核心是前两层。

### 长期引导三步骤

1. **抛出共鸣炸弹**：找到角色最易引发共鸣的情感锚点（梦想、仇恨、恐惧）
2. **让读者变见证者**：展示角色付出和挣扎，每一步伴随收获
3. **让读者变参与者**：通过足够铺垫和细节，产生命运共同体感

### 短期情绪引导

短期靠独立事件冲突。**直白冲突比繁杂情节更容易引起共鸣**。

两种事件类型：
- **推动情节发展的事件**：让读者对角色处境产生认同
- **塑造人物性格的事件**：让读者对角色思想性格产生认同

开篇必须选择塑造人物性格的事件——先认同角色这个人才关心角色的事。

### 情绪代入的陷阱

读者未代入主角前：主角弱势可以引起同情，但**敌人弱势也同样引起同情**。读者还没建立认同时，不要把对手写得可怜。

### 情绪文笔技法

- **句长跟着情绪和节奏走**：紧张、决断处用短句提速，铺垫、沉淀处用长句蓄势；短句是提速工具，不是默认底色，别通篇拆短
- **突发词**：骤然、猛然只用在真实突发处
- **动作词**：抽、划、留下——画面感强，情绪外化
- **修饰词**：精准克制地使用形容词，不堆砌
- **直写还是外化**：直写准确就直写；行为能多带信息时才用行为，别为外化堆无功能的小动作。**以乐写悲**：角色在最悲伤时表现开心，情绪张力更强（赴死的人很开心，往往比哭更悲）

## 情绪落到纸面：六条硬要求

写到某段自己都觉得「太平」「看不出喜怒哀乐」时，按这六条过。

**一、情绪第一时间给到读者：直写为主，肢体为辅**：态度和心理能用情绪词、情态词直接写出来的就直接写——哈哈大笑、冷笑、嗤笑、皮笑肉不笑、脸色发白、语气发颤、一字一顿、嗓子低下去。读者第一眼接住他什么态度，不用自己分析。

- 直写是主：笑法、语气、称呼、眼神看谁不看谁，是读者读态度的第一落点
- 肢体是辅：停笔、缩手、喉头动一下、退半步，用来加码、控节奏、藏潜台词，不替代情绪词
- 受限的是抽象的心理陈述（他知道/她觉得/心里一沉）：一章不超三处，只用来说明**他为什么这么做**
- 每个主要角色有自己的情态标记或身体习惯（有人动怒先笑，有人越气越慢，有人受压就磨墨），别人用不了

**二、强度分级**：同一章里几件事的轻重差着好几倍，反应强度必须跟着差；全章一个温度，读者会判定这个人木。写前给本章事件排一次轻重，最强的那件事要有更明显的身体反应（失手、停住、退一步）、余韵（事后一个动作、一段沉默），后面几段的行文跟着它变（短句、断段、少解释）。

**三、事后必须变**：情绪释放或强行压住之后，人物要有看得见的位移——改了一个决定、换了一种称呼、少说了一句话、多留了一样东西。释放完什么也没变 = 白写；调动完没有释放 = 读者憋屈。

**四、一章之内至少两次反向**：全章一个温度最要命。情绪的每一次起落都要有触发（新信息、新人物、身体变故、关系位移），不能无由地转向；章末可以在暴烈之后用最软的一句收住。

**五、心理用问句和短句写**：主角的疑惑、犹豫、盘算，能写成问句就别写成陈述——「正方体石块怎么会发出这种声音？」「这东西埋在地下多少年了？」读者跟着一起疑，比「他心中充满疑惑」快得多。盘算可以写三步（试一个办法 → 这一步为什么不行 → 换一个），每一步的"不行"都要有具体理由。

**六、让旁人替你加码**：主角自己的反应之外，再给一个旁观者的反应（同伴脸色一变、旁人失笑、对手瞳孔一缩、外人一声惊呼）。旁人的反应是最省字数的强度放大器。

## 读者情绪的位置（写完自查）

写每个场景前想清：读者此刻在「平静 → 调动 → 释放 → 爽」的哪一环，下一步该调动还是该释放；不必逐段标注。只有调动没有释放 = 读者憋屈弃书；只有释放没有调动 = 爽感平淡无力；调动程度决定释放爽度（仇恨拉多满，打脸就多爽）。
